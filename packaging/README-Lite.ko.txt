Private Translator Lite 0.1.0
================================

1. PrivateTranslator-Lite.exe를 더블클릭합니다.
2. 잠시 뒤 기본 브라우저에서 번역 화면이 열립니다.
3. 브라우저에서 쓰는 동안 프로그램 창을 열어 둡니다.
4. 사용을 마치면 프로그램 창을 닫습니다. 모델 엔진도 함께 종료됩니다.

- 번역 요청은 127.0.0.1 안에서만 처리되며 인터넷 번역 API로 보내지 않습니다.
- 기록은 현재 Windows 계정으로 보호한 AES-256-GCM 암호문으로 저장합니다.
- 기록 저장을 끈 요청은 기록고에 넣지 않습니다.
- 기본 기록 위치: %LOCALAPPDATA%\PrivateTranslator
- 프로그램 폴더를 지워도 기록은 자동 삭제하지 않습니다.

Hy-MT2 1.8B Q4_K_M과 llama.cpp b9966 Windows x64 CPU 런타임을 포함합니다.
실행 전 모델·런타임 SHA-256과 실제 로드된 모델 ID를 확인합니다.

현재 릴리즈는 코드 서명이 없어 Windows가 알 수 없는 게시자 경고를 표시할 수 있습니다.
