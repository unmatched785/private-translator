Private Translator 0.1.0 for Windows x64
==========================================

RECOMMENDED START
Double-click PrivateTranslator-Lite.exe. Use PrivateTranslator-Quality.exe only when you want the optional private Hy-MT2 7B endpoint in the model selector.

Both executables share the included Hy-MT2 1.8B model and llama.cpp runtime. Keep the console window open while using the browser interface; closing it stops the managed model server.

Translation traffic and the encrypted history vault stay on your PC. Quality has no automatic cloud fallback. Read README.ko.txt for Korean instructions and THIRD_PARTY_NOTICES.md for component licenses.

This release is not code-signed. Verify the SHA-256 sidecar published with the GitHub release.
