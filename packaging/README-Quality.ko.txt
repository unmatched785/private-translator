Private Translator Quality 0.1.0
===================================

1. PrivateTranslator-Quality.exe를 더블클릭합니다.
2. 기본 Hy-MT2 1.8B 모델은 즉시 사용할 수 있습니다.
3. 선택형 Hy-MT2 7B 항목은 호환되는 개인 모델 서버가 필요합니다.
4. 사용을 마치면 프로그램 창을 닫습니다.

인터넷 번역 API와 자동 클라우드 폴백은 없습니다. 기록과 승인 번역 자산 버전은 이 Windows PC의 암호화 기록고에 저장합니다.

첫 릴리즈에는 용량이 큰 7B 모델팩을 포함하지 않습니다.
현재 릴리즈는 코드 서명이 없어 Windows가 알 수 없는 게시자 경고를 표시할 수 있습니다.
