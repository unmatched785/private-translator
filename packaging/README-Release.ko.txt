Private Translator 0.1.0 Windows x64
======================================

보통은 PrivateTranslator-Lite.exe를 더블클릭합니다. 선택형 개인 Hy-MT2 7B 서버 항목이 필요할 때만 PrivateTranslator-Quality.exe를 사용하세요.

두 실행 파일은 포함된 Hy-MT2 1.8B 모델과 llama.cpp 런타임 하나를 함께 사용합니다. 브라우저에서 쓰는 동안 프로그램 창을 열어 두며, 창을 닫으면 모델 서버도 종료됩니다.

번역 통신과 암호화 기록고는 PC 안에 남습니다. Quality도 클라우드로 자동 전환하지 않습니다. 구성 요소 라이선스는 THIRD_PARTY_NOTICES.md를 확인하세요.

현재 릴리즈는 코드 서명이 없습니다. GitHub 릴리즈에 함께 올린 SHA-256 파일로 ZIP을 확인할 수 있습니다.
